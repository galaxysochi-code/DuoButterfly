How it works

Close the lid.The desktop follows.

DUO Butterfly reads your MacBook’s lid-angle sensor and redraws the desktop at every angle. It’s not a pre-recorded animation.

Installation

Install in
a few minutes.

Detailed installation guide ↗
  1. Download the ZIP file from the latest GitHub release, unzip it and drag DUO Butterfly to your Applications folder.
  2. The app isn’t notarized by Apple, so macOS blocks the first launch. Go to System Settings → Privacy & Security and click Open Anyway.
  3. Allow Screen Recording when macOS asks. DUO Butterfly needs this permission only to create the visual effect on the built-in display — it does not record video or audio.
