Installation

Install in
a few minutes.

Detailed installation guide ↗
  1. Download the ZIP file from the latest GitHub release, unzip it and drag DUO Butterfly to your Applications folder.
  2. The app isn’t notarized by Apple, so macOS blocks the first launch. Go to System Settings → Privacy & Security and click Open Anyway.
  3. Allow screen recording when macOS asks. DUO Butterfly uses this permission only to create the visual effect on the built-in display. It doesn’t record video or audio.
