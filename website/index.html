Read the installation guide ↗
  1. Download the ZIP from the latest GitHub Release, unzip it and move DUO Butterfly to Applications.
  2. The app is not notarized by Apple. After the first opening attempt, go to System Settings → Privacy & Security and choose Open Anyway.
  3. Allow screen recording when prompted. The effect needs access to the built-in display; it does not capture audio.
